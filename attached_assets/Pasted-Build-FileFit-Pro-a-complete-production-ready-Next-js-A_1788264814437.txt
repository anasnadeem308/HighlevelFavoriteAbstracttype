### `/tools/passport-photo-resizer`

* 35×45 mm preset
* 300 DPI default
* calculate/show pixel dimensions
* crop/fit while preserving aspect ratio
* preview/download
* optional compression

* front + back image upload
* A4 portrait/landscape
* side-by-side or top/bottom layout
* adjustable margins/spacing
* preview

* client-side PDF using jsPDF
